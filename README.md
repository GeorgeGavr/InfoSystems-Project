Βήματα Εισαγωγής Αρχείου .tar
Άνοιγμα του Budibase: https://budibase.com/

Συνδεθείτε στο Budibase.
Βεβαιωθείτε ότι έχετε ανοιχτό το workspace στο οποίο θέλετε να κάνετε την εισαγωγή.

Μετάβαση στην ενότητα Εισαγωγής:

Στο dashboard του Budibase, βρείτε την επιλογή για εισαγωγή ή διαχείριση εφαρμογών.
Κάποιες φορές η επιλογή για εισαγωγή μπορεί να βρίσκεται στις ρυθμίσεις ή στο μενού της εφαρμογής που χρησιμοποιείτε.

Επιλογή Αρχείου .tar:

Όταν σας ζητηθεί να επιλέξετε ένα αρχείο προς εισαγωγή, πατήστε το κουμπί "Επιλογή Αρχείου" και αναζητήστε το .tar αρχείο στον υπολογιστή σας.
Επιλέξτε το αρχείο και κάντε κλικ στο "Άνοιγμα".

Προεπισκόπηση και Επαλήθευση:

Μετά την επιλογή του αρχείου, το Budibase θα αναλύσει το περιεχόμενο του αρχείου .tar.
Ελέγξτε αν όλα τα δεδομένα και οι εφαρμογές είναι σωστά και έτοιμα για εισαγωγή.

Ολοκλήρωση της Εισαγωγής:

Πατήστε το κουμπί "Εισαγωγή" για να ολοκληρωθεί η διαδικασία.
Περιμένετε λίγα δευτερόλεπτα για να ολοκληρωθεί η εισαγωγή. Το Budibase θα δημιουργήσει τα αντίστοιχα δεδομένα ή εφαρμογές σύμφωνα με το περιεχόμενο του αρχείου .tar.

Επαλήθευση:

Μετά την ολοκλήρωση της εισαγωγής, μπορείτε να περιηγηθείτε στην εφαρμογή  στο Budibase για να βεβαιωθείτε ότι όλα τα δεδομένα ή οι εφαρμογές έχουν εισαχθεί σωστά.
